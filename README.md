# Temperature Converter 

A lightweight, responsive web application built with vanilla JavaScript that allows users to convert temperatures seamlessly between Celsius and Fahrenheit.

## Features
- **Bi-directional Conversion:** Convert from Celsius to Fahrenheit and vice versa.
- **Form Validation:** Integrated alerts to prompt users to select a unit before submitting.
- **Responsive Design:** A clean, modern UI that works across various screen sizes.
- **Real-time Feedback:** Instant results displayed directly within the application card.

## Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling with Flexbox for centering and shadow effects.
- **JavaScript (ES6):** Logic for mathematical conversions and DOM manipulation.

## How it Works
The application uses the following standard formulas:
- **Celsius to Fahrenheit:** $F = (C \times 9/5) + 32$
- **Fahrenheit to Celsius:** $C = (F - 32) \times 5/9$
